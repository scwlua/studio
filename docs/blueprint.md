# **App Name**: Checkmate

## Core Features:

- The Opening Gambit (AI Goal Decomposition): When a user creates a new 'Campaign' (goal), they simply write a sentence. The Grandmaster AI analyzes this input and automatically generates a suggested project plan, breaking the campaign down into logical phases and actionable 'Moves' (tasks). The user can then review, edit, and approve this strategic plan.
- The Daily Strategy (AI-Powered Dashboard): The AI analyzes all pending 'Moves,' deadlines, user's calendar, and learned productivity patterns to presents the top 3-5 recommended 'Moves' for the day, ordered by strategic importance.
- Threat Analysis (Proactive Procrastination Assistant): The Grandmaster AI learns which types of tasks the user consistently postpones. If a 'Move' is deferred more than twice, the AI will intervene with a helpful prompt, suggesting a 'counter-move' to the user's block.
- Resource Reconnaissance (Contextual AI Assistance): When a user views a task, an AI tool provides contextual help. It can scan the user's connected Google Drive for files with related keywords and suggest them as attachments. It can suggest external resources.
- Endgame Analysis (Gamified Weekly Review): Every Sunday, Checkmate delivers a 'Weekly Endgame' report, visualizing wins (completed Moves), analyzes productivity patterns, and highlights any 'blunders' (missed critical tasks), offering strategic advice for the upcoming week. Includes achievements and badges for milestones.
- User Authentication: Enable user sign-up and login with Google and Email/Password.
- Dynamic 'Today's Strategy' view: Displays top 3-5 recommended 'Moves' for the day, ordered by strategic importance, including a 'Focus Move' and a 'Quick Win'.

## Style Guidelines:

- Primary color: Deep orange (#D45500) for calls-to-action, priorities, and notifications. This hue is associated with productivity and energy.
- Background color: Charcoal (#333333), providing a sophisticated backdrop.  The darkness will allow the orange primary color to pop.
- Accent color: Ivory (#FAF0E6), used sparingly for text and subtle highlights to add contrast. Ivory sits adjacent to orange in the color wheel and evokes a feeling of clean sophistication.
- Headline font: 'Poppins', sans-serif, for headlines and other short, impactful text.
- Body font: 'PT Sans', sans-serif, for body text to be easily legible in blocks of text.
- Card-based design for tasks and goals. Emphasize clarity and focus, with ample white space.
- Subtle animations when completing a task, like a chess piece being satisfyingly placed on a square, to enhance the feeling of making a successful 'move.'
